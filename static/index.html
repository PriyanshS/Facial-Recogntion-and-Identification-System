Classical Digital Image Processing (DIP) Pipeline

Visualizes each foundational image transformation step mandated by the Image & Video Processing curriculum.

Stage 1

Input Image & Face Localization

Raw RGB frame analyzed with Viola-Jones Haar Cascade detector to localize facial bounding coordinates.

ROI: Detecting...
Stage 2

Grayscale Luminance Extraction

Perceptually weighted luminance formula: Y = 0.299R + 0.587G + 0.114B separating luminance from chrominance.

Dynamic Range: [0, 255]
Stage 3

YUV Color Space — Y Channel

Alternative color space luminance isolation. The Y channel is resilient to color cast variations.

Channel 0 (Luminance)
Stage 3b (Homomorphic)

Homomorphic Filtering (Log-FFT)

Frequency-domain log-transform: &ln;(I) = &ln;(L) + &ln;(R). Attenuates low-frequency illumination (shadows) and amplifies invariant facial reflectance.

2D-FFT | D0=20 | γ_L=0.75, γ_H=1.25
Stage 4

Global Histogram Equalization

Cumulative Distribution Function (CDF) mapping to redistribute intensity across full spectrum.

Global Contrast Stretch
Stage 5

CLAHE Local Contrast Enhancement

Contrast-Limited Adaptive Histogram Equalization operates on local 8×8 tiles with clipping limit = 2.0.

Tile Grid: 8x8 | Clip: 2.0
Stage 6

Gaussian Spatial Low-Pass Smoothing

Convolves with a 3×3 Gaussian kernel (σ = 0.8) to attenuate high-frequency sensor noise.

Kernel: 3x3 | σ = 0.8
Stage 7

Median Filter (Non-linear)

Replaces pixels with neighborhood median to eliminate impulsive salt-and-pepper artifacts.

Window: 3x3 Non-Linear
Stage 8

Sobel Gradient Magnitude

Directional kernels Gx and Gy approximate spatial derivatives: |G| = √(Gx² + Gy²).

Operators: Gx, Gy (ksize=3)
Stage 9

Canny Edge Detection & Contours

Multi-stage pipeline: non-maximum suppression (NMS) and hysteresis double-thresholding (50/150).

Thresh: T_low=50, T_high=150
Stage 10

Normalized Fixed Face ROI

Uniform 100×100 pixel cropped face ready for deterministic feature template generation.

Resolution: 100 × 100 px (uint8)

Local Binary Pattern (LBP) Histogram

256-bin micro-texture frequency distribution (8-neighborhood circular comparison).

256 Bins

LBP captures fine-grained skin micro-textures, wrinkles, and boundary transitions invariant to monotonic illumination shifts.

Sobel Gradient Orientation Distribution

Magnitude-weighted orientation histogram across 36 angular bins (0° to 360°).

36 Bins

Weighted by gradient magnitude |G|, highlighting the dominant angular directions of structural face contours.

Combined Numerical Feature Template Architecture

Serialized float32 vector stored in SQLite database BLOB column.
